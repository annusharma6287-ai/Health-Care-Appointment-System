# CareSlot: Healthcare Appointment System

A simple website for booking doctor appointments, built with HTML, CSS and
JavaScript. It runs in the browser and needs no backend.

## Features
- Browse doctors and filter by specialty
- Choose a day (next 7 days) and an available time slot
- Booked and past slots are disabled
- Form validation for name and 10-digit mobile number
- View and cancel appointments in the "My appointments" tab
- Responsive layout with light and dark mode

## Tech used
HTML, CSS, JavaScript, localStorage

## How to run
1. Download or clone this repository.
2. Keep `index.html`, `style.css` and `script.js` in the same folder.
3. Open `index.html` in your browser.

## Note
This is a demo. Appointments are saved in your browser only, and no real
bookings are made.
